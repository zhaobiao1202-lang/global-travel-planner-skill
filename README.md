# Global Travel Planner Skill

面向全球自驾游的中文规划 Skill：根据出发地、目的地、日期、同行人年龄、预算、车辆、补能方式和驾驶上限，生成可编辑的行程草案。

## 下载与安装

1. 下载本仓库中的 `global-travel-planner-workbuddy-20260905.zip`。
2. WorkBuddy：进入“专家·技能·连接器” → “技能” → “添加技能” → “上传技能”，选择该 ZIP 文件即可导入。
3. 其他支持 Agent Skills 的工具：下载 `SKILL.md`，或直接使用 ZIP 中的 `global-travel-planner` 文件夹。

## 范围

- 仅用于自驾游规划；不包含航班、火车或其他主要交通方式。
- 不代替实时地图、天气、酒店库存、充电站状态或道路封闭信息；这些内容需要在出发前核验。
- 不会自动预订、付款或联系商家。

## 适用场景

家庭、情侣、朋友和独自出行的公路旅行；支持纯电、混动、汽油和柴油车，并覆盖驾驶疲劳、补能/加油、预算、住宿餐食、出行清单和 Plan B。
